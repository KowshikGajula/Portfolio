# Kowshik Gajula — SAP ABAP Consultant Portfolio

A premium, dark-first personal brand site for an SAP ABAP Consultant. Built to read
like a $5,000 custom-designed enterprise technology portfolio — not a template.

**Live:** [portfolio-three-nu-11.vercel.app](https://portfolio-three-nu-11.vercel.app)

---

## Tech stack

| Layer | Choice |
| --- | --- |
| Build | Vite 5 + React 19 + TypeScript (strict) |
| Styling | Tailwind CSS 3 with CSS custom-property design tokens |
| Animation | Framer Motion, GSAP ScrollTrigger, Lenis smooth scroll |
| 3D backdrop | Vanta `NET` effect over three.js |
| Icons | Lucide + local brand marks |
| Fonts | Space Grotesk (display), Inter (body), JetBrains Mono (code) |

### How the animation stack fits together

- **Lenis** provides smooth scrolling. It is driven from the **GSAP ticker** rather
  than its own rAF loop, so **ScrollTrigger** scrubs stay perfectly in sync
  (`src/components/layout/SmoothScroll.tsx`).
- **Framer Motion** handles component-level entrances, layout transitions and
  `AnimatePresence` panels.
- **Vanta `NET`** draws the animated network behind the hero. It is loaded with a
  dynamic import so three.js never blocks first paint.

#### Notes on the Vanta integration (non-obvious, load-bearing)

1. `vanta`'s published UMD bundle does **not** export the registered effect, so the
   effect is imported from its ESM source: `vanta/src/vanta.net.js`.
2. three.js must be passed explicitly via `options.THREE` — Vanta otherwise expects
   a global `window.THREE`.
3. three.js removed the `VertexColors` enum that Vanta still references; it is
   supplied as `true`, which is the modern equivalent.
4. If WebGL is unavailable the effect fails silently and the CSS grid backdrop
   remains — the hero never looks broken.

## Editing your content

**Nothing personal is hard-coded into components.** Everything lives in `src/data/`:

| File | What it controls |
| --- | --- |
| `profile.ts` | Name, title, location, summary, contact links, availability, hero terminal |
| `skills.ts` | The six technical expertise categories |
| `projects.ts` | The five projects, case studies and architecture chains |
| `journey.ts` | The professional timeline |
| `certifications.ts` | Certification cards |
| `architecture.ts` | The interactive integration flow |

### Placeholders you must replace

Anything wrapped in `« … »` in `src/data/` is a placeholder:

- `contact.email`, `contact.linkedin`
- `contact.formEndpoint` (optional — see below)
- Every `employer`, `period` and `role` in `journey.ts`
- `credentialId` / `verifyUrl` in `certifications.ts`

Company names, employment dates, clients and personal contact details were
deliberately **not** invented.

### Contact form

`contact.formEndpoint` in `profile.ts` is optional:

- **Empty (default):** the form validates, then opens the visitor's mail client
  with the message pre-filled. Works with no backend at all.
- **Set to an endpoint** (Formspree, Web3Forms, your own API): the form POSTs
  JSON and reports success or failure in the UI.

Either way you get field-level validation, honeypot spam protection, and
success/error feedback.

### Résumé

`public/resume.pdf` is generated by `scripts/generate-resume.mjs` — a
dependency-free PDF writer. Edit the `resume` object at the top of that file and
run `npm run resume`.

### Open Graph image

`public/og.png` (1200×630) is rendered from a standalone HTML card by
`scripts/generate_og.py`, so its typography and gradient match the site exactly.
Regenerate it with:

```bash
python scripts/generate_og.py
```

It needs Chrome (`channel="chrome"`) and Playwright. If you change the brand
colours or headline, re-run it so link previews stay in sync. `public/sitemap.xml`
is hand-maintained — update it if the domain changes.

## Design system

Colour is driven by CSS custom properties in `src/index.css` and exposed through
Tailwind tokens, so the light/dark theme flips with a single class on `<html>`.

> **Gotcha:** colour tokens are stored as RGB channels (`--text: 233 239 252`) and
> wrapped in `<alpha-value>` so opacity modifiers like `bg-canvas/80` work.
> Never name a token `base` — it collides with Tailwind's `fontSize.base` and
> `text-base` would then emit a colour as well as a font size.

## Quality checks

```bash
npx vite preview --port 4173     # then, in another shell:
python scripts/smoke_test.py     # runtime + interaction smoke test
python scripts/layout_audit.py   # responsive layout audit

# Both accept a URL, so the same checks can run against production:
python scripts/smoke_test.py https://portfolio-three-nu-11.vercel.app/
python scripts/layout_audit.py https://portfolio-three-nu-11.vercel.app/
```

filtering, case-study expansion, architecture tabs, theme toggle, form

390 / 360 px.
